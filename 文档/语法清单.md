# 语法清单（一页速查）

> **用途**：写代码时对照；**不是规格**。完整语义见 [AI语言设计规格](AI语言设计规格.md)，逐条细节见 [语法速查](语法速查.md)。
> 记号：`[ ]` 可选，`( )` 分组，`…` 重复。

---

## 1. 文件与模块

| 项 | 写法 | 说明 |
|---|---|---|
| 声明文件 | `*.tu` | **人写、人签**：`spec`、`target`、`effects`、`external` |
| 实现文件 | `*.eln` | **可整份重写**：只有 `func`，**没有声明** |
| 成对规则 | 同名同目录 | `calculator.tu` ↔ `calculator.eln` |
| 引入外部库 | `link "libc";` | 模块级，放在文件顶部 |
| 注释 | `// …` | 行注释；不支持块注释 |

---

## 2. 声明（只在 `.tu`）

```elench
spec name(params) -> RetType {
    effects { fs, io };                 // 空集合写 {}
    target {
        time:       { max: O(n) };      // 上界（必须单调，且只能收不能放）
        allocation: { max: 0 };         // 分配：**精确**判定
    };
    guarantees { is_sorted(ret) };      // 语义承诺（可检查的进检查器）
    assume { n(xs) <= 1024 };           // 显式假设（会被打印）
    repeats { log(n) };                 // 算法性质：循环上界
    external { read_file: O(n) };       // 外部调用登记
    benchmodel { n = xs.length() };     // 输入规模模型
}
```

| 关键字 | 作用 | 可信位 |
|---|---|---|
| `spec` | 声明一个函数 | — |
| `target` | **成本上界**（time / allocation） | **#2** |
| `effects` | 副作用集合 | **#5** |
| `guarantees` | 语义承诺 | **#6** |
| `repeats` | 循环次数上界 | **#3** |
| `benchmodel` | 基准的规模模型 | **#7** |
| `external` | 外部调用成本 | **#8** |
| `assume` | 假设（显式、会打印） | 辅助 |
| 递归深度 | `depth: …` | **#4** |

> **七个可信位 = 2–8**（#1 `cost` 由编译器生成、#9 `??[cost]` 已退休）。

## 3. 类型

| 类别 | 写法 | 备注 |
|---|---|---|
| 整数 | `u64` / `i64` | 无浮点（成本模型是操作数计数） |
| 布尔 | `bool` | `true` / `false` |
| 字节串 | `Vec<u8>` | 字符串就是它 |
| 引用 | `Vec<u64>&` | **参数位置**，可变借用 |
| 容器 | `Vec<T>` / `Map<K,V>` / `Set<T>` / `Deque<T>` | 方法见 [内建函数](内建函数.md) |
| 可空 | `Option<T>` | `option_some` / `option_none` |
| 结果 | `Result<T,E>` | 错误必须处理或显式忽略 |
| 函数类型 | `func(Vec<u64>) -> u64` | **只能出现在参数位置** |
| 枚举 | `enum Json { Null, Num(u64), Arr(Vec<Json>) }` | **变体之间用逗号** |
| 结构体 | `struct Entry { key: Vec<u8>, value: Json }` | 字段用 `:` |

## 4. 语句

| 语句 | 写法 |
|---|---|
| 常量 | `const u64 n = xs.length();` |
| 变量 | `u64 i = 0;`（**不用 `let`**） |
| 赋值 | `i = i + 1;` |
| 条件 | `if (cond) { … } else { … }` |
| 循环 | `while (cond) { … }` |
| 遍历 | `for (u64 x : xs) { … }` |
| 遍历映射表 | `for_each(m, f);`（κ = `n(m) × (1 + k(f)) + n(m)`） |
| 匹配 | `match (v) { Num(n) => …, Null => … }` |
| 并行 | `parallel { a(); b(); }`（成本取**和**） |
| 返回 | `return expr;` |
| 跳出 | `break;` / `continue;` |

---

## 5. 表达式

| 类别 | 写法 |
|---|---|
| 算术 | `+ - * / %` |
| 比较 | `== != < <= > >=` |
| 逻辑 | `&& \|\| !` |
| 索引 | `xs[i]` |
| 调用 | `f(a, b)` |
| 方法 | `xs.length()` / `m.get(k)` / `s.push(x)` |
| 格式化 | `format("x = {}, y = {:>2}", x, y)`（**位置洞**，编译期查 arity/类型） |
| 长度 | `xs.length()`（**不要写 `len(xs)`**） |

## 6. 决策点与分档（`?!`）

```elench
spec choose(xs) -> u64 {
    target { time: { max: O(xs.length() * log(xs.length())) } };
    // ?! 表示"以下实现都算达标，按实测挑"
}
```

| 步骤 | 命令 |
|---|---|
| 1. 声明候选 | `.tu` 里写 `?!` |
| 2. 实测 | `dsh measure` → 生成分档表 |
| 3. 构建 | `dsh build`（缺表 → `E-Dispatch-NoTable`） |

## 7. 已退役的写法（**会直接报错，不是警告**）

| 退役 | 现在用 |
|---|---|
| `fn` | `func` |
| `val` / `var` | `const` / `u64 i = …` |
| `end fn` | `}` |
| `len(x)` | `x.length()` |

## 8. 诊断码前缀

| 前缀 | 类别 | 例 |
|---|---|---|
| `E-Lex-*` | 词法 | `E-Lex-UnknownChar` |
| `E-Parse-*` | 语法 | `E-Parse-UnexpectedTop` |
| `E-Spec-*` | 契约签名 | `E-Spec-SigMismatch` |
| `E-Fn-*` | 函数/声明 | `E-Fn-NoSpec` |
| `E-Effect-*` | 效果 | `E-Effect-Missing` |
| `E-Dispatch-*` | 分档表 | `E-Dispatch-NoTable` |
| `E-Format-*` | 格式化 | `E-Format-Arity` |
| `B-*` | 构建门禁 | `B-17`（`pending` 候选） |
| `W-*` | 警告 | `W-Format-Dynamic` |

## 9. 一行速记

> **`.tu` 写声明，`.eln` 写实现；`cost` 问上界，`build --deny-debt` 判生死；**
> **`target` 是人签的，κ 是机器算的；**两者一比，就是全部。
