# 课堂 3 分钟演示（教师模板）

> **照着敲就能跑完。** 四条命令全跑一遍 **约 68 秒**（实测：`cost` 各 0.1 秒 + 出表 33.3 秒 + 出图约 34 秒）。
> **赶时间就跳过第 3 步（出图）**，剩下两步只要 34 秒。
> 三个样例都随仓库提供，不需要联网、不需要装任何依赖。

## 0. 一句话先讲清（30 秒）

> **在这门语言里，「这个函数多贵」是签名的一部分，编译器能替你算。**
> 你写 `target { max: O(n) }`，工具给一个自己的上界 κ；
> **κ 超了就报错，给不出就说「无法判定」，不猜。**

## 1. 第一眼：让工具算给你看（5 秒）

```bash
python src/dsh.py cost 文档/样例/max_pair_sum
```

真实输出：

```text
✓ max_pair_sum  κ ≤ 9 + n(xs)×(4 + 4 + n(xs)×24 + 24 + 5) + 4 + 4 + n(xs)×24 + …
```

**指着那个 `n(xs)×(…n(xs)×24…)` 说**：

- 它就是 `O(n²)` —— **两层循环，工具自己看出来的**；
- 而作者只在 `.tu` 里写了 `target { time: { max: O(xs.length() * xs.length()) } }`；
- **两条对上 → 达标**。

## 2. 让它自己跑一遍，出「紧度表」（33 秒）

```bash
python tools/tightness_table.py 文档/样例/max_pair_sum
```

真实输出（节选）：

| 规模 n | κ（上界） | 实测 ops | κ÷实测 |
|---|---|---|---|
| 1 | 133 | 29 | 4.59 |
| 8 | 2072 | 717 | 2.89 |
| 16 | 7168 | 2691 | 2.66 |
| 64 | 102256 | 41423 | 2.47 |

**这一列 `κ÷实测` 从 4.59 收敛到 2.47** —— 说明**上界的阶是对的**，只多了一个约 2.5 倍的常数。

> **这是全场最重要的一句**：如果 κ 的阶错了，这个比值会**一路涨**（比如 4.6 → 8 → 20…）。
> 它稳住了，才说明"工具算的"和"真跑的"是同一个量级。

## 3. 一张图（10 秒，可选）

```bash
python src/dsh.py export 文档/样例/max_pair_sum --full --out=/tmp/demo.svg
```

打开它。第一面板「**上界与实测**」把 `target` / `承诺` / `典型实测` 画在**同一纵轴**上。

> ⚠️ **务必补一句**：**图是示意，表是证据。**
> 图的纵轴是**对数刻度**，两条线看着贴在一起可能差好几倍；
> 要引用数字，**只引第 2 步那张表**——它每格都能重跑出来。

## 4. 收个尾：二维也能算（5 秒）

```bash
python src/dsh.py cost 文档/样例/blur
```

真实输出：

```text
✓ blur  κ ≤ 4 + n(h)×(4 + 2 + n(w)×16 + 16 + 5) + 4 + 2 + n(w)×16 + 16 + 5 + …
```

**这个函数有 `w` 和 `h` 两个参数**，工具给的是 `h × (w × 16 + …)` —— **二维乘法，不是"未知"**。

> **它也能出紧度表**（2026-11-07 修好之后）：`data` 里写字面量当默认值，
> 把参数写进 `scale` 就会覆盖它。同一套命令换模块名即可：
>
> ```bash
> python tools/tightness_table.py 文档/样例/blur
> ```
>
> κ÷实测 从 **2.42 收到 1.20**。**修之前**这张表是假的（规模列在变、参数不变，7 行数字全一样）——
> 这是个值得讲给学生听的例子：**工具出错时，它给的数看起来一样"正常"。**

## 5. 如果学生问「那它和复杂度分析课有什么区别」

> 课本让你**证明**一个上界；这门语言让你**声明**一个上界，然后**机器来查**。
> 查不过就红，查不了就说查不了——**"未知"是一等公民**，不是失败。
