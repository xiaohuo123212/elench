# `ee/` —— 保留区（不在此仓库）

**这个目录是占位，现在没有代码。**

## 它保留什么

面向**企业/机构**的能力，典型是：

| 方向 | 说明 |
|---|---|
| **跨模块 / 全仓分析** | 一个入口函数调多个模块时的 κ 组合（当前未做，M2 第一优先） |
| **组织级成本预算与门禁策略** | 谁能改 `target`、预算审批流、多仓库汇总 |
| **审计留痕与合规导出** | 成本契约的签署记录、变更历史、外部审计接口 |

## 为什么单独留一个目录

**为了把"开源到什么程度"这件事写清楚，而不是含糊**：

- **本仓库（Apache-2.0）**：语言、编译器、检查器、成本推导、门禁、`dsh` 工具链——**全部开源**；
- **`ee/`**：企业侧集成与规模化能力，**不在本仓库**。

## 一条承诺

**核心能力不做"开源阉割"**：本仓库里的检查器与成本推导是**完整**的；
`ee/` 里只放**规模化与组织级**能力（跨仓库、审批流、审计导出），**不放单机功能**。

> 如果你发现某个"必须有才能用"的能力被留在 `ee/`，**那是 bug**，请开 issue。
