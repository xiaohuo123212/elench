## 0.6.40 —— 2026-11-04

- **E4：循环次数由分支决定时，上界现在算得出来。**
  `i = 0; if (c) { i = xs.length(); } while (i > 0) { i = i - 1; }`
  以前拿不到初值 → κ 里出现 `n(i)` → 判决 `unknown`；现在 `n(xs)` → 判 `ok`。
- 做法（AST 路线）：`monotone_decreasing` 区分**循环体外赋值**（改初值）与
  **循环体内赋值**（必须仍是减法）；初值为字面量 0 时用体外赋值覆盖，
  因为 `max(0, x) = x` 而 u64 计数器不可能小于 0。
- 新增 `test_e4_branch_bound.py` 钉住这个行为。

## 0.6.32 —— 2026-11-04

## 0.6.31 —— 2026-11-03
